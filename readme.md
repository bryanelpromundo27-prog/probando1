# Parcial de Diseño Web - ISI-FE2301

Este proyecto corresponde a la evaluación parcial del curso Diseño Web del semestre **2026-II** en la **Universidad de Ciencias y Humanidades (UCH)**. Consiste en un sitio web adaptativo y semántico de tipo Portafolio Profesional Multimedia.

## Tecnologías Utilizadas
- **HTML5:** Estructuración nativa con etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Estilos avanzados mediante selectores id, clases, maquetación adaptada con cajas flotantes (`float`), transiciones y transformaciones interactivas (`transform: scale`).
- **Diseño Adaptativo (RWD):** Implementación de breakpoints a través de `@media` queries para dispositivos móviles y de escritorio.
- **Optimización SEO:** Configuración estricta de metaetiquetas de indexación y adaptabilidad de pantalla en el encabezado del documento.
